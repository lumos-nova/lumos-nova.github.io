Kafka_4.1.0(Kraft模式)集群安装

环境准备

  • 系统：Ubuntu 22.04

  • JDK：21

  • Kafka: 4.1.0

  • CPU：4核+

  • 内存：8GB+（生产环境建议16GB+）

  • ip（你自己的集群IP）主机名角色node idBroker端口Controller端口
    192.168.8.151node1Broker，Controller190929093
    192.168.8.152node2Broker，Controller290929093
    192.168.8.153node3Broker，Controller390929093

  • 所有节点既是 Broker 又是 Controller，但进程分离部署

  • 使用 Kafka 内置的 KRaft 模式，不需要 ZooKeeper

  • 所有节点必须能互相访问。

下载 Kafka

访问 Apache Kafka 官网，选择 Binary Downloads，下载 kafka_2.13-4.1.0.tgz（支持 Windows/Linux）。

依赖项

需提前安装并配置 JAVA_HOME 环境变量。

安装

将压缩包解压至短路径目录（如 /opt/kafka/kafka_2.13-4.1.0），进入Kafka目录

mkdir -p /opt/kafka
tar -zxvf kafka_2.13-4.1.0.tgz
cp -R kafka_2.13-4.1.0 /opt/kafka/
cd /opt/kafka/kafka_2.13-4.1.0

修改 /etc/hosts 文件

127.0.0.1 localhost

# The following lines are desirable for IPv6 capable hosts
::1     ip6-localhost ip6-loopback
fe00::0 ip6-localnet
ff00::0 ip6-mcastprefix
ff02::1 ip6-allnodes
ff02::2 ip6-allrouters

192.168.8.151 node1
192.168.8.152 node2
192.168.8.153 node3

修改kafka配置文件

打开 config\server.properties，修改以下关键参数：

# node1 配置
process.roles=broker,controller
# 节点ID，要求集群内唯一,每个节点的ID要不一样
node.id=1
# controller集群成员列表，集群内部选举和同步元数据
controller.quorum.voters=1@node1:9093,2@node2:9093,3@node3:9093

listeners=PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:9093
# IP修改为自己的IP
# 侦听器名称、主机名和代理将向客户端公布的端口(broker对外地址)
advertised.listeners=PLAINTEXT://192.168.8.151:9092,CONTROLLER://192.168.8.151:9093

log.dirs=/opt/kafka/kafka-logs
num.partitions=3

# node2 配置
process.roles=broker,controller
# 节点ID，要求集群内唯一,每个节点的ID要不一样
node.id=1
# controller集群成员列表，集群内部选举和同步元数据
controller.quorum.voters=1@node1:9093,2@node2:9093,3@node3:9093

listeners=PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:9093
# IP修改为自己的IP
# 侦听器名称、主机名和代理将向客户端公布的端口(broker对外地址)
advertised.listeners=PLAINTEXT://192.168.8.152:9092,CONTROLLER://192.168.8.152:9093

log.dirs=/opt/kafka/kafka-logs
num.partitions=3

# node3 配置
process.roles=broker,controller
# 节点ID，要求集群内唯一,每个节点的ID要不一样
node.id=1
# controller集群成员列表，集群内部选举和同步元数据
controller.quorum.voters=1@node1:9093,2@node2:9093,3@node3:9093

listeners=PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:9093
# IP修改为自己的IP
# 侦听器名称、主机名和代理将向客户端公布的端口(broker对外地址)
advertised.listeners=PLAINTEXT://192.168.8.153:9092,CONTROLLER://192.168.8.153:9093

log.dirs=/opt/kafka/kafka-logs
num.partitions=3

初始化集群并启动

cd /opt/kafka/kafka_2.13-4.1.0
# 1. 生成唯一集群ID（首次启动执行），三个节点任选一个节点，仅执行一次，在格式化时使用
KAFKA_CLUSTER_ID=$(bin/kafka-storage.sh random-uuid)

# 2. 在每个节点格式化存储（首次启动），KAFKA_CLUSTER_ID 取生成的集群ID
kafka-storage.sh format -t $KAFKA_CLUSTER_ID -c config/server.properties

# 3. 按顺序启动节点（先启动控制器节点）
# 节点1
nohup bin/kafka-server-start.sh config/kraft/server.properties &

# 等待10秒后启动节点2
nohup bin/kafka-server-start.sh config/kraft/server.properties &

# 等待10秒后启动节点3
nohup bin/kafka-server-start.sh config/kraft/server.properties &

# 4. 等待20s验证集群状态
bin/kafka-broker-api-versions.sh --bootstrap-server 127.0.0.1:9092
bin/kafka-topics.sh --bootstrap-server 192.168.1.101:9092 --list

开机自启动 Kafka 服务

  1. 创建服务文件 vim /etc/systemd/system/kafka.service
[Unit]
Description=Apache Kafka server (KRaft mode)
Documentation=https://kafka.apache.org/documentation/
After=network.target
 
[Service]
Type=simple
User=charlie
Group=charlie
ExecStart=/opt/kafka/kafka_2.13-4.1.0/bin/kafka-server-start.sh /opt/kafka/kafka_2.13-4.1.0/config/server.properties
ExecStop=/opt/kafka/kafka_2.13-4.1.0/bin/kafka-server-stop.sh
Restart=on-failure
TimeoutStopSec=90
LimitNOFILE=65536
Environment="KAFKA_HEAP_OPTS=-Xmx1G -Xms1G"
 
# 设置 Kafka 日志输出（可选）
StandardOutput=syslog
StandardError=syslog
SyslogIdentifier=kafka
 
[Install]
WantedBy=multi-user.target
  1. 修改服务后需要重新加载
sudo systemctl daemon-reload

# 查看Kafka服务状态
sudo systemctl status kafka
