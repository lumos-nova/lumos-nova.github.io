KAFKA

下载 Kafka

访问 Apache Kafka 官网，选择 Binary Downloads，下载 kafka_2.13-4.1.0.tgz（支持 Windows/Linux）。

依赖项

Kafka 4.0 基于 JDK 17 编译，需提前安装并配置 JAVA_HOME 环境变量。

安装

将压缩包解压至短路径目录（如 D:\IDEenv\Java_env\kafka_2.13-4.1.0），避免路径过长导致错误。

配置日志目录

创建 Kafka 日志目录（如 D:\\IDEenv\\Java_env\\kafka-logs）。

修改配置文件

打开 config\server.properties，修改以下关键参数：

############################# Log Basics #############################

# A comma separated list of directories under which to store log files
# log.dirs=/tmp/kraft-combined-logs
# 修改此处为以下配置
log.dirs=D:\\IDEenv\\Java_env\\kafka-logs
num.partitions=1
num.recovery.threads.per.data.dir=1

初始化存储目录

生成集群 ID：

cd D:\IDEenv\Java_env\kafka_2.13-4.1.0\
bin\windows\kafka-storage.bat random-uuid

输出示例如下：

2025-06-29T09:18:15.572495900Z main ERROR Reconfiguration failed: No configuration found for '7852e922' at 'null' in 'null'
uaYzGeFqTeqAIpTvEGmyQg

上述日志中有个错误提示可以忽略。记录此ID：uaYzGeFqTeqAIpTvEGmyQg，此ID为集群唯一标识，初始化日志目录时需要使用

打开 config\server.properties，增加以下关键参数：

# 控制器选举配置（单机模式示例）
controller.quorum.voters=1@localhost:9093

关键变化说明(官方包默认配置没改为新的)
Kafka 4.x 版本配置变化：
❌ 不再使用：controller.quorum.bootstrap.servers={host}:{port}
✅ 改为使用：controller.quorum.voters=node_id@host:port
格式说明：
1@127.0.0.1:9093中的 1是节点ID（即为server.properties的node.id）
127.0.0.1:9093是控制器监听地址
集群模式下：controller.quorum.voters=node_id_1@host:port,node_id_2@host:port,node_id_3@host:port

Kafka 4.x 默认使用 KRaft 模式（Kafka Raft Metadata），取代了旧版的 ZooKeeper。在 KRaft 模式下，controller.quorum.voters 是必需配置，用于指定集群的控制器节点。

格式化日志目录

cd D:\IDEenv\Java_env\kafka_2.13-4.1.0\
bin\windows\kafka-storage.bat format -t uaYzGeFqTeqAIpTvEGmyQg -c config\server.properties

# 若提示‘命令语法不正确’请按如下方式执行
# 1. 进入配置文件 config目录
# 2. 执行如下命令
"你的kafka-storage.bat的文件路径" format -c server.properties -t uaYzGeFqTeqAIpTvEGmyQg

验证：检查 D:\\IDEenv\\Java_env\\kafka-logs 目录下是否生成 meta.properties 和 bootstrap.checkpoint 文件。

启动 Kafka

在 bin\windows 目录下执行：

kafka-server-start.bat ..\..\config\server.properties
